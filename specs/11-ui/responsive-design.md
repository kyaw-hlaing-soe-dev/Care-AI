# CareAI Responsive Design Specification

**Status:** Active  
**Version:** 1.0  
**Last Updated:** 2026-08-08  
**Related:** [Accessibility](./accessibility.md), [QA Checklist](../13-testing/qa-checklist.md)

**CARE-RESP-001 — P0 / IMPLEMENTED in layouts; NOT VERIFIED as release QA:** Test 1440×900, 1366×768, 1280×720, 1024×768, 820×1180, 768×1024, 430×932, 412×915, 390×844, 375×812, 360×640, and 320×568.

Requirements: no horizontal overflow/clipped components; readable charts and form labels; 44px minimum touch targets; mobile-specific single-column forms/scenes; responsive navigation; normal document scrolling with mobile keyboards; no CTA overlap; dashboard/history cards adapt without fake data. Landing hero limits small screens to compact metrics and a scaled doctor scene; desktop preserves richer visual composition.
